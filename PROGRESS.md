# Progress — superseded

This file was the build log for **Phase 1** of the original single-user app: the
editor, autosave, focus mode, responsive layouts, reading view, search, settings,
Google auth and the offline cache. All of it shipped, and the product moved a
long way past it — Dayspring is now a multi-tenant subscription journal on web,
macOS and iOS.

It is kept out of the way rather than maintained. **Do not read it for current
state**; it describes a single-user tool with no payments, no onboarding and no
multi-tenancy, and it points at a source-of-truth document that has since been
archived.
