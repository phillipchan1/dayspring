# Scripture flow prototype

Part of [Dayspring prototypes](../README.md). Self-guided mockup — fictional journal ("Anna").

**Live:** [prototypes.usedayspring.app/scripture/#intro](https://prototypes.usedayspring.app/scripture/#intro) · short link: [scripture.prototypes.usedayspring.app](https://scripture.prototypes.usedayspring.app/#intro)

## Run locally

```bash
cd prototypes/scripture
npm install
npm run dev
```

Opens at `/scripture/#intro`. Footer notes on every screen. Last screen sends feedback via shared `POST /api/feedback`.
